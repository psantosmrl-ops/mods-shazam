# Mods Shazam

- painel-agentes: painel ao vivo com o que os agentes fazem
- memoria: notas compartilhadas entre janelas do mesmo PC
- planejar-executar: o Claude planeja, ChatGPT ou Gemini executa no navegador
- controlar-pc: mouse, teclado, programas, pastas, navegador e captura de tela no Windows

Instalar (no prompt do Claude Code):

    /plugin marketplace add psantosmrl-ops/mods-shazam
    /plugin install painel-agentes@mods-shazam
    /plugin install memoria@mods-shazam
    /plugin install planejar-executar@mods-shazam
    /plugin install controlar-pc@mods-shazam
